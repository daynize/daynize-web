과거의 반사실
실제와 다른 상황을 가정할 때는 시간부터 나눠요. 지금 다른 상황인지, 이미 지난 일을 바꾸는지 보세요.
동사 중심으로 보기
if + 과거형
would + 원형
if + 과거형
would + 원형
지금의 반사실은 이프절에 과거형을 써요. 결과는 우드와 원형으로 나타내며, 비동사는 워를 쓸 수 있죠.
동사 중심으로 보기
if + had + 과거분사
would have + 과거분사
if + had + 과거분사
would have + 과거분사
지난 일의 반사실은 이프절에 해드와 과거분사를 써요. 결과도 우드 해브와 과거분사로 맞춥니다.
동사 중심으로 보기
would: 예상 결과
could: 능력·가능성
would: 예상 결과
could: 능력·가능성
쿠드는 할 수 있었을 가능성이나 능력을 나타내요. 우드와 뜻이 같지는 않으며, 문맥에 맞춰 고르세요.
01 / 기본
내가 지금 부자라면 더 큰 집을 살 텐데요.
❌ Incorrect · 고쳐 볼 표현
If I were rich now, I would bought a bigger house.
⭕ Correct · 이렇게 말해요
IfIwererichnow,Iwouldbuyabiggerhouse.
현재 반사실 결과에서 would 뒤에는 원형 buy를 쓰며 과거형 bought를 쓰지 않는다.
02 / 기본
지금 시간이 더 있다면 너를 도울 텐데요.
❌ Incorrect · 고쳐 볼 표현
If I had more time now, I would helps you.
⭕ Correct · 이렇게 말해요
IfIhadmoretimenow,Iwouldhelpyou.
현재의 가정에서 had는 have의 과거형이다. would 뒤의 help에는 s를 붙이지 않는다.
03 / 기본
그녀가 지금 여기 있다면 답을 알 텐데요.
❌ Incorrect · 고쳐 볼 표현
If she were here now, she would knows the answer.
⭕ Correct · 이렇게 말해요
Ifshewereherenow,shewouldknowtheanswer.
주어가 she여도 would 뒤에는 원형 know를 쓴다. 반사실 be에 were가 가능하다.
04 / 중급
내가 일찍 떠났더라면 기차를 탔을 텐데요.
❌ Incorrect · 고쳐 볼 표현
If I had left early, I would have catch the train.
⭕ Correct · 이렇게 말해요
IfIhadleftearly,Iwouldhavecaughtthetrain.
과거 반사실 결과는 would have 뒤에 과거분사 caught를 쓴다.
05 / 중급
공부했더라면 시험에 합격했을 텐데요.
❌ Incorrect · 고쳐 볼 표현
If I had study, I would have passed the exam.
⭕ Correct · 이렇게 말해요
IfIhadstudied,Iwouldhavepassedtheexam.
과거 반사실의 if절은 had와 과거분사 studied를 결합한다.
06 / 중급
비가 오지 않았더라면 우리는 밖에서 놀았을 텐데요.
❌ Incorrect · 고쳐 볼 표현
If it had not rained, we would have play outside.
⭕ Correct · 이렇게 말해요
Ifithadnotrained,wewouldhaveplayedoutside.
부정 과거 반사실 조건은 had not rained이며 결과에는 과거분사 played가 필요하다.
07 / 중급
차가 있었다면 우리는 그곳까지 운전해 갈 수도 있었을 텐데요.
❌ Incorrect · 고쳐 볼 표현
If we had had a car, we could have drove there.
⭕ Correct · 이렇게 말해요
Ifwehadhadacar,wecouldhavedriventhere.
첫 had는 완료 조동사, 둘째 had는 소유 동사의 과거분사다. could have 뒤에는 driven을 쓴다.
08 / 고급
내가 지금 수영할 줄 안다면 그들과 함께할 수 있을 텐데요.
❌ Incorrect · 고쳐 볼 표현
If I could swam now, I could join them.
⭕ Correct · 이렇게 말해요
IfIcouldswimnow,Icouldjointhem.
could 뒤에는 원형 swim을 쓴다. 여기서 could는 가정 속 능력과 참여 가능성을 나타낸다.
09 / 고급
내가 너라면 오늘 그 제안을 거절할 텐데요.
❌ Incorrect · 고쳐 볼 표현
If I were you, I would refusing the offer today.
⭕ Correct · 이렇게 말해요
IfIwereyou,Iwouldrefusetheoffertoday.
현재 반사실 조언의 결과는 would refuse이며 ing를 바로 붙이지 않는다.
10 / 고급
네가 알려 줬더라면 나는 어제 올 수 있었을 텐데요.
❌ Incorrect · 고쳐 볼 표현
If you had told me, I could have came yesterday.
⭕ Correct · 이렇게 말해요
Ifyouhadtoldme,Icouldhavecomeyesterday.
could have 뒤에는 과거형 came이 아니라 과거분사 come을 쓴다. 올 수 있었을 가능성을 말하며 반드시 왔을 것이라고 단정하지 않는다.

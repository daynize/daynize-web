# BASIC COURSE 21 · 정말 한다는 강조, 더 그렇다는 비교

분류: 동사 강조와 비교급

학습 목표: 긍정문의 do/does/did+원형 강조와 형용사·부사 비교급의 형태 및 수식어를 구분한다.

썸네일·목록 문구: **does 뒤에 likes를 쓰거나 비교급 앞에 more를 또 붙이고 있나요?**

## 제작 상태

**대본·제작 지시서 완료 / TTS 미생성 / MP4 미렌더링.** 아래는 목표 장면 슬롯이다. 한국어·영어의 실제 시작·종료 시각과 단어 강조 시각은 오디오 생성 후 확정한다.

목표 130초, 허용 100–135초 / 1080×1920 / 30fps / 한국어 Jian (Premium) / 영어 Samantha.

## 개념·대조 전체 대본

| 목표 슬롯 | 한국어 실제 발화 원고 | 중앙 화면 | 그래픽 지시 |
|---|---|---|---|
| 00:00–00:10 | 정말 한다고 강조할 때는 긍정문에도 두를 넣어요. 주어와 시간에 맞춰 더즈나 디드를 고릅니다. | do / does / did + 동사원형 | 첫 예문의 do에 강조 파형, 뒤 like에 원형 표시. |
| 00:10–00:20 | 강조하는 말이 시제와 주어 정보를 맡으니 뒤 동사는 원형이에요. 더즈 뒤에도 에스를 다시 붙이지 않죠. | 강조 조동사에 정보 / 본동사는 원형 | does·did 칸에 문법 정보 모으고 본동사 칸은 원형 유지. |
| 00:20–00:30 | 비교급은 형용사뿐 아니라 부사에도 있어요. 이알이나 모어 중 알맞은 형태를 쓰고 둘을 겹치지 마세요. | 형용사·부사 비교 / more faster는 중복 | 성질 비교와 행동 속도 비교를 두 줄로 배치. |
| 00:30–00:40 | 베터와 워스 같은 불규칙 비교급도 익히세요. 훨씬 더는 머치로 강조하고 베리는 비교급 앞에 쓰지 않아요. | better / worse / much + 비교급 | 불규칙 형태 표와 비교 차이의 크기를 나타내는 눈금. |

도입 영어는 화면으로만 표시한다. 예문·표현을 재사용하고 독립적인 영어 예문 발화를 추가하지 않는다.

## 대조 예문 10개

각 행은 한국어 발화 후 영어 정답을 읽는다. 오답은 발화하지 않는다. 영어로도 가능하지만 의도한 뜻이 다른 대비는 교정 설명에서 구분한다.

### 01 · 기본 · 00:40–00:47

- 한국어 / Jian (Premium): 네가 의심해도 나는 이 노래를 정말 좋아해요.
- Correct / Samantha: **I do like this song, despite your doubts.**
- Incorrect 또는 의도한 뜻과 불일치 / 화면만: I do likes this song, despite your doubts.
- 교정 포인트: 긍정문을 강조하는 do 뒤에는 원형 like를 쓰며 likes를 쓰지 않는다.
- 주황색 강조: do / like
- 그래픽·구조: 의심 말풍선에 응답하는 do 강조와 like 원형 표시.

### 02 · 기본 · 00:47–00:54

- 한국어 / Jian (Premium): 네가 뭐라 해도 그녀는 답을 정말 알아요.
- Correct / Samantha: **She does know the answer, whatever you say.**
- Incorrect 또는 의도한 뜻과 불일치 / 화면만: She does knows the answer, whatever you say.
- 교정 포인트: 삼인칭 단수 표시는 does가 맡으므로 본동사 know에 s를 더하지 않는다.
- 주황색 강조: does / know
- 그래픽·구조: she → does의 수 정보와 원형 know를 분리.

### 03 · 기본 · 00:54–01:01

- 한국어 / Jian (Premium): 네 말과 달리 나는 어제 전화했어요.
- Correct / Samantha: **I did call you yesterday, contrary to your claim.**
- Incorrect 또는 의도한 뜻과 불일치 / 화면만: I did called you yesterday, contrary to your claim.
- 교정 포인트: 과거 강조는 did가 맡으므로 본동사는 과거형 called가 아닌 원형 call이다.
- 주황색 강조: did / call
- 그래픽·구조: 어제 시간 정보는 did에, 전화 동작은 call에 연결.

### 04 · 중급 · 01:01–01:09

- 한국어 / Jian (Premium): 우리는 네가 생각하는 것보다 도움이 정말 필요해요.
- Correct / Samantha: **We do need help more than you think.**
- Incorrect 또는 의도한 뜻과 불일치 / 화면만: We does need help more than you think.
- 교정 포인트: 현재 주어 we에는 강조 do를 쓰고 does를 쓰지 않는다.
- 주황색 강조: do / need
- 그래픽·구조: we 복수 주어와 do 연결, need 원형 유지.

### 05 · 중급 · 01:09–01:17

- 한국어 / Jian (Premium): 이 가방은 네 것보다 더 가벼워요.
- Correct / Samantha: **This bag is lighter than yours.**
- Incorrect 또는 의도한 뜻과 불일치 / 화면만: This bag is more lighter than yours.
- 교정 포인트: lighter 자체가 비교급이므로 more를 앞에 겹쳐 쓰지 않는다.
- 주황색 강조: lighter / than
- 그래픽·구조: 두 가방 무게 눈금과 lighter 단일 비교 표시.

### 06 · 중급 · 01:17–01:25

- 한국어 / Jian (Premium): 그녀는 나보다 더 빨리 달려요.
- Correct / Samantha: **She runs faster than I do.**
- Incorrect 또는 의도한 뜻과 불일치 / 화면만: She runs more faster than I do.
- 교정 포인트: 달리는 방식을 꾸미는 부사 fast의 비교급은 faster이며 more를 중복하지 않는다.
- 주황색 강조: runs / faster
- 그래픽·구조: 달리기 속도 눈금에 부사 비교 표시.

### 07 · 중급 · 01:25–01:34

- 한국어 / Jian (Premium): 이 문제는 앞의 문제보다 더 어려워요.
- Correct / Samantha: **This problem is more difficult than the last one.**
- Incorrect 또는 의도한 뜻과 불일치 / 화면만: This problem is difficulter than the last one.
- 교정 포인트: difficult의 표준 비교급은 more difficult이며 difficulter로 만들지 않는다.
- 주황색 강조: more difficult / than
- 그래픽·구조: 문제 난이도 두 칸과 more difficult 묶음.

### 08 · 고급 · 01:34–01:44

- 한국어 / Jian (Premium): 그녀는 나보다 영어를 더 잘해요.
- Correct / Samantha: **She speaks English better than I do.**
- Incorrect 또는 의도한 뜻과 불일치 / 화면만: She speaks English more better than I do.
- 교정 포인트: speaks를 꾸미는 well의 비교급은 better이며 more를 덧붙이지 않는다.
- 주황색 강조: speaks / better
- 그래픽·구조: 말하기 수행 비교와 well → better 변화 표시.

### 09 · 고급 · 01:44–01:54

- 한국어 / Jian (Premium): 이 결과는 어제 결과보다 더 나빠요.
- Correct / Samantha: **This result is worse than yesterday’s result.**
- Incorrect 또는 의도한 뜻과 불일치 / 화면만: This result is badder than yesterday’s result.
- 교정 포인트: 결과의 성질을 설명하는 bad의 비교급은 worse이며 badder가 아니다.
- 주황색 강조: is / worse
- 그래픽·구조: 결과 두 개를 비교하고 bad → worse 불규칙 변화 표시.

### 10 · 고급 · 01:54–02:05

- 한국어 / Jian (Premium): 이 버전은 이전 버전보다 훨씬 더 좋아요.
- Correct / Samantha: **This version is much better than the previous one.**
- Incorrect 또는 의도한 뜻과 불일치 / 화면만: This version is very better than the previous one.
- 교정 포인트: 형용사 good의 비교급 better는 차이의 크기를 나타내는 much로 강조한다. very를 바로 붙이지 않는다.
- 주황색 강조: much / better
- 그래픽·구조: 두 버전 차이 눈금 확대, much → better 연결.

## 한 줄 요약 · 02:05–02:10

Jian (Premium): “강조 조동사 뒤에는 원형을 두고, 비교급은 형태와 강조어를 겹치지 않게 고르세요.”

## 강의별 모션·자막 지시

- 한글 중앙 (540,650), 오답 (540,890), 정답 (540,1120), 교정 (540,1460). 안전 여백 좌우 100px, 주요 내용 y=300–1540.
- 한글 48–56px, 영어 정답 58–68px, 오답 42–48px. 긴 문장은 의미 단위로 2–3줄. 확대 여유 공간을 포함해 실제 폰트로 검수한다.
- 크림 #F6F1E8, 차콜 #252525, 필수 강조 #FF6648. 작은 주황색 글자는 차콜 강조면 위에 둔다. 오답은 연한 레드 면 #FBE3E0와 진한 레드 #A33C35.
- 한글 발화 시작에 번역 공개 → 한글 끝에 오답 공개 → 0.3초 이상의 간격 후 영어 발화와 정답 동시 공개. 영어 정답 선공개 금지.
- 동사·핵심 표현의 실제 발화 시작에 중앙 기준 scale 1.00→1.10(0.10초), 1.10→1.00(0.14초). 다른 단어·줄바꿈은 이동하지 않는다.
- 설명용 연결선은 양쪽 대상 공개 후 나타난다. 새로운 규칙을 암시하는 장식·불필요한 캐릭터·효과는 추가하지 않는다.
- seek-safe 단일 paused GSAP 타임라인. 영상 중 타이머·네트워크·무작위 값에 의존하지 않고 역방향 탐색에서 정답 숨김도 복원한다.

## 실제 오디오 확정 절차

1. 지정 성우로 개념 4개, 한글 예문 10개, 영어 정답 10개, 요약 1개를 각각 생성한다.
2. ffprobe로 25개 원본 오디오 길이를 측정한다. 무음·읽기 여유를 더한 합이 135초를 넘으면 원고를 줄여 다시 생성한다. 말속도만 무리하게 올리지 않는다.
3. 문장별 원본에서 단어 시각을 정렬하고 원문 일치·발화 구간 내부 여부를 검사한다. 긴 무음이 섞인 전체 트랙의 보간 시각은 사용하지 않는다.
4. 실제 시작·종료 시각을 plans 데이터의 null 필드에 기록하고 목표 슬롯을 실제 길이에 맞게 재배분한다. 요약까지 100–135초 안에 배치한다.
5. 자막과 확대를 최종 오디오 시각에 연결하고 실제 청취·프레임 검수 후 확정한다. 자동 정렬만으로 100% 또는 1프레임 정확도를 보장하지 않는다.

## 교육 정확성 주의

- 1~4번은 일반동사 긍정문의 do/does/did 강조, 5~10번은 비교급으로 구성한다.
- 강조 do는 일반동사에 적용한다. be나 이미 조동사가 있는 모든 문장에 do를 추가한다고 일반화하지 않는다.
- do/does/did 강조는 발화 강세가 중요하지만 이 파일은 원고 데이터만 제공하며 음성 강세·길이를 검증하지 않는다.
- 형용사 good/bad와 부사 well/badly는 각각 better/worse로 비교될 수 있다.
- 비교급은 much, far, a lot, even 등으로 수식할 수 있다. very를 비교급에 바로 붙이는 기본 구조는 쓰지 않는다.
- more와 er을 기계적으로 겹치지 않는다. 형용사별 허용 형태 차이는 있지만 more faster는 표준 비교급이 아니다.

## 출력 검수

- 예문 10개·난도 3/4/3·한글 선행·영어 정답 후행·오답 무발화·지정 성우 일치.
- 모든 장면 브라우저 검사, 텍스트 넘침·색상 대비·역방향 seek 검사, 최종 MP4 대표 장면과 오디오 디코딩 확인.
- 로컬 제작은 별도 강의별 평가 요청 없이 진행하되 실제 게시·외부 서비스 변경은 별도 작업 범위다.

# BASIC COURSE 17 · 두 문장을 명사 하나로 연결하기

분류: 주격·목적격 관계대명사

학습 목표: 관계절의 주어·목적어 자리를 확인하고 제한적 목적격 관계대명사만 생략한다.

썸네일·목록 문구: **관계절에서 who를 쓰고도 he나 him을 다시 넣고 있나요?**

## 제작 상태

**대본·제작 지시서 완료 / TTS 미생성 / MP4 미렌더링.** 아래는 목표 장면 슬롯이다. 한국어·영어의 실제 시작·종료 시각과 단어 강조 시각은 오디오 생성 후 확정한다.

목표 130초, 허용 100–135초 / 1080×1920 / 30fps / 한국어 Jian (Premium) / 영어 Samantha.

## 개념·대조 전체 대본

| 목표 슬롯 | 한국어 실제 발화 원고 | 중앙 화면 | 그래픽 지시 |
|---|---|---|---|
| 00:00–00:10 | 같은 사람이나 사물을 말하는 두 문장은 관계절로 연결할 수 있어요. 겹치는 자리를 먼저 찾으세요. | The woman helped me. / The woman lives nearby. | 첫 예문을 두 문장으로 펼치고 공통 명사를 연결. |

| 00:20–00:30 | 목적어 역할이면 관계절 안에 주어가 따로 있어요. 명사를 좁혀 주는 목적격 관계대명사는 생략할 수 있죠. | 관계절: 주어 + 동사 + 목적어 빈칸 | 주격과 목적격의 빈자리 위치를 두 줄로 비교. |

도입 영어는 화면으로만 표시한다. 예문·표현을 재사용하고 독립적인 영어 예문 발화를 추가하지 않는다.

## 대조 예문 10개

각 행은 한국어 발화 후 영어 정답을 읽는다. 오답은 발화하지 않는다. 영어로도 가능하지만 의도한 뜻이 다른 대비는 교정 설명에서 구분한다.

### 01 · 기본 · 00:40–00:47

- 한국어 / Jian (Premium): 나를 도와준 여자는 근처에 살아요.
- Correct / Samantha: **The woman who helped me lives nearby.**
- Incorrect 또는 의도한 뜻과 불일치 / 화면만: The woman who she helped me lives nearby.
- 교정 포인트: who가 helped의 주어이므로 she를 다시 넣지 않는다.
- 주황색 강조: who / helped
- 그래픽·구조: 두 문장의 공통 여자를 who로 연결하고 she 중복 제거.

### 02 · 기본 · 00:47–00:54

- 한국어 / Jian (Premium): 그가 산 전화기는 꽤 비싸요.
- Correct / Samantha: **The phone which he bought is quite expensive.**
- Incorrect 또는 의도한 뜻과 불일치 / 화면만: The phone which he bought it is quite expensive.
- 교정 포인트: which가 bought의 목적어 자리와 연결되므로 it을 다시 넣지 않는다.
- 주황색 강조: which / bought
- 그래픽·구조: phone을 bought 뒤의 빈 목적어 자리로 연결.

### 03 · 기본 · 00:54–01:01

- 한국어 / Jian (Premium): 우리 옆에 사는 개는 자주 짖어요.
- Correct / Samantha: **The dog that lives next door often barks.**
- Incorrect 또는 의도한 뜻과 불일치 / 화면만: The dog lives next door often barks.
- 교정 포인트: that이 관계절의 주어이므로 생략하면 두 동사를 연결할 구조가 사라진다.
- 주황색 강조: that / lives
- 그래픽·구조: 주절 barks와 관계절 lives를 구분하고 that 주어 표시.

### 04 · 중급 · 01:01–01:09

- 한국어 / Jian (Premium): 네가 어제 만난 남자는 내 선생님이에요.
- Correct / Samantha: **The man who you met yesterday is my teacher.**
- Incorrect 또는 의도한 뜻과 불일치 / 화면만: The man who you met him yesterday is my teacher.
- 교정 포인트: 목적격 who는 가능하지만 같은 목적어를 him으로 반복하지 않는다.
- 주황색 강조: who / met
- 그래픽·구조: you를 관계절 주어로, who를 met의 목적어로 연결.

### 05 · 중급 · 01:09–01:17

- 한국어 / Jian (Premium): 내가 어제 산 책은 이미 여기 있어요.
- Correct / Samantha: **The book I bought yesterday is already here.**
- Incorrect 또는 의도한 뜻과 불일치 / 화면만: The book I bought it yesterday is already here.
- 교정 포인트: 제한적 목적격은 생략할 수 있다. 생략해도 bought 뒤에 it을 다시 채우지 않는다.
- 주황색 강조: I bought / book
- 그래픽·구조: 생략된 관계대명사 자리와 목적어 빈칸을 연결.

### 06 · 중급 · 01:17–01:25

- 한국어 / Jian (Premium): 입구를 막고 있는 차는 톰 것이에요.
- Correct / Samantha: **The car which blocks the entrance belongs to Tom.**
- Incorrect 또는 의도한 뜻과 불일치 / 화면만: The car which it blocks the entrance belongs to Tom.
- 교정 포인트: which가 blocks의 주어라서 it은 중복이다.
- 주황색 강조: which / blocks
- 그래픽·구조: car → which → blocks 주어 연결 표시.

### 07 · 중급 · 01:25–01:34

- 한국어 / Jian (Premium): 내가 수리한 의자는 이제 사용하기에 안전해요.
- Correct / Samantha: **The chair that I repaired is safe to use now.**
- Incorrect 또는 의도한 뜻과 불일치 / 화면만: The chair that I repaired it is safe to use now.
- 교정 포인트: that은 repaired의 목적어 역할이며 it을 덧붙이지 않는다. 이 that은 생략도 가능하다.
- 주황색 강조: that / repaired
- 그래픽·구조: chair와 repaired 뒤 빈자리 연결, 생략 가능 표시.

### 08 · 고급 · 01:34–01:44

- 한국어 / Jian (Premium): 근처에 사는 내 여동생 미아는 자전거로 출근해요.
- Correct / Samantha: **My sister Mia, who lives nearby, cycles to work.**
- Incorrect 또는 의도한 뜻과 불일치 / 화면만: My sister Mia, that lives nearby, cycles to work.
- 교정 포인트: 이미 특정된 미아에 추가 설명을 붙이는 쉼표 관계절에는 that을 쓰지 않는다.
- 주황색 강조: who / lives
- 그래픽·구조: Mia를 특정 인물로 표시하고 쉼표 안의 who절을 분리.

### 09 · 고급 · 01:44–01:54

- 한국어 / Jian (Premium): 내가 어제 산 이 노트북은 잘 작동해요.
- Correct / Samantha: **This laptop, which I bought yesterday, works well.**
- Incorrect 또는 의도한 뜻과 불일치 / 화면만: This laptop, I bought yesterday, works well.
- 교정 포인트: 쉼표로 덧붙인 비제한적 관계절은 목적격이라도 관계대명사를 생략하지 않는다.
- 주황색 강조: which / bought
- 그래픽·구조: which가 목적어 역할이어도 쉼표 경계에서는 유지 표시.

### 10 · 고급 · 01:54–02:05

- 한국어 / Jian (Premium): 우리가 논의한 프로젝트는 다음 주에 시작돼요.
- Correct / Samantha: **The project about which we spoke starts next week.**

- 교정 포인트: 전치사 바로 뒤에서는 which를 쓰며 that은 쓰지 않는다. 전치사를 뒤에 두는 구조와 구분한다.
- 주황색 강조: about which / spoke
- 그래픽·구조: about which를 한 덩어리로 묶고 전치사 바로 뒤 자리 강조.

## 강의별 모션·자막 지시

- 한글 중앙 (540,650), 오답 (540,890), 정답 (540,1120), 교정 (540,1460). 안전 여백 좌우 100px, 주요 내용 y=300–1540.
- 한글 48–56px, 영어 정답 58–68px, 오답 42–48px. 긴 문장은 의미 단위로 2–3줄. 확대 여유 공간을 포함해 실제 폰트로 검수한다.
- 크림 #F6F1E8, 차콜 #252525, 필수 강조 #FF6648. 작은 주황색 글자는 차콜 강조면 위에 둔다. 오답은 연한 레드 면 #FBE3E0와 진한 레드 #A33C35.
- 한글 발화 시작에 번역 공개 → 한글 끝에 오답 공개 → 0.3초 이상의 간격 후 영어 발화와 정답 동시 공개. 영어 정답 선공개 금지.
- 동사·핵심 표현의 실제 발화 시작에 중앙 기준 scale 1.00→1.10(0.10초), 1.10→1.00(0.14초). 다른 단어·줄바꿈은 이동하지 않는다.
- 설명용 연결선은 양쪽 대상 공개 후 나타난다. 새로운 규칙을 암시하는 장식·불필요한 캐릭터·효과는 추가하지 않는다.
- seek-safe 단일 paused GSAP 타임라인. 영상 중 타이머·네트워크·무작위 값에 의존하지 않고 역방향 탐색에서 정답 숨김도 복원한다.

## 실제 오디오 확정 절차

1. 지정 성우로 개념 4개, 한글 예문 10개, 영어 정답 10개, 요약 1개를 각각 생성한다.
2. ffprobe로 25개 원본 오디오 길이를 측정한다. 무음·읽기 여유를 더한 합이 135초를 넘으면 원고를 줄여 다시 생성한다. 말속도만 무리하게 올리지 않는다.
3. 문장별 원본에서 단어 시각을 정렬하고 원문 일치·발화 구간 내부 여부를 검사한다. 긴 무음이 섞인 전체 트랙의 보간 시각은 사용하지 않는다.
4. 실제 시작·종료 시각을 plans 데이터의 null 필드에 기록하고 목표 슬롯을 실제 길이에 맞게 재배분한다. 요약까지 100–135초 안에 배치한다.
5. 자막과 확대를 최종 오디오 시각에 연결하고 실제 청취·프레임 검수 후 확정한다. 자동 정렬만으로 100% 또는 1프레임 정확도를 보장하지 않는다.

## 교육 정확성 주의

- 제한적 관계절에서는 사람에 who/that, 사물에 which/that을 사용할 수 있다.
- 목적격 who도 현대 영어에서 널리 쓰인다. whom만 정답이라고 하지 않는다.
- 생략은 제한적 관계절의 목적격에 적용하며, 주격이나 비제한적 관계절에는 적용하지 않는다.
- 전치사가 관계대명사 바로 앞에 오면 that과 생략형을 쓰지 않는다. 전치사를 뒤에 남긴 구조와 구분한다.
- 스크린의 두 문장은 첫 예문의 연결 과정을 펼친 것이며 추가 독립 예문이 아니다.

- 모든 장면 브라우저 검사, 텍스트 넘침·색상 대비·역방향 seek 검사, 최종 MP4 대표 장면과 오디오 디코딩 확인.
- 로컬 제작은 별도 강의별 평가 요청 없이 진행하되 실제 게시·외부 서비스 변경은 별도 작업 범위다.

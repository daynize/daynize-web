# BASIC COURSE 20 · 지금의 가정과 과거의 가정을 나누기

분류: 현재·과거 반사실 조건문

학습 목표: 현재 반사실과 과거 반사실을 구분하고 would와 could의 결과·가능성 차이를 이해한다.

썸네일·목록 문구: **이미 지나간 일을 가정하면서 if절에 단순과거만 쓰고 있나요?**

## 제작 상태

**대본·제작 지시서 완료 / TTS 미생성 / MP4 미렌더링.** 아래는 목표 장면 슬롯이다. 한국어·영어의 실제 시작·종료 시각과 단어 강조 시각은 오디오 생성 후 확정한다.

## 대조 예문 10개

각 행은 한국어 발화 후 영어 정답을 읽는다. 오답은 발화하지 않는다. 영어로도 가능하지만 의도한 뜻이 다른 대비는 교정 설명에서 구분한다.

### 01 · 기본 · 00:40–00:47

- 한국어 / Minsu (Enhanced): 내가 지금 부자라면 더 큰 집을 살 텐데요.
- Correct / Samantha: **If I were rich now, I would buy a bigger house.**
- Incorrect 또는 의도한 뜻과 불일치 / 화면만: If I were rich now, I would bought a bigger house.
- 교정 포인트: 현재 반사실 결과에서 would 뒤에는 원형 buy를 쓰며 과거형 bought를 쓰지 않는다.
- 주황색 강조: were / would buy
- 그래픽·구조: 현재의 실제와 부자인 가정 경로를 분리.

### 02 · 기본 · 00:47–00:54

- 교정 포인트: 현재의 가정에서 had는 have의 과거형이다. would 뒤의 help에는 s를 붙이지 않는다.

- 그래픽·구조: 현재 가정의 had와 원형 help를 연결.

## 교육 정확성 주의

- 현재 반사실 조건문의 과거형은 과거 시점이 아니라 현실과의 거리를 나타낼 수 있다.
- 반사실 be에는 were를 모든 인칭에 쓸 수 있다. 구어의 I/he/she was를 무조건 오류로 표시하지 않는다.
- 과거 반사실은 보통 if+had+과거분사와 would/could have+과거분사를 결합한다. 혼합 조건문은 별도의 시간 의미가 있다.
- would는 예상되는 가정 결과, could는 능력·가능성을 나타낸다. could를 언제나 불가능했다는 단정으로 해석하지 않는다.
- 가정 조건 if절에는 보통 would를 넣지 않지만, 의지·정중한 요청 등 예외가 있으므로 if 뒤 would는 항상 금지라고 하지 않는다.
- 현재 조건 대비에는 현재·과거 결과 시간을 명시하거나 형태 오류를 사용해 가능한 혼합 조건문을 단순 오답 처리하지 않는다.
